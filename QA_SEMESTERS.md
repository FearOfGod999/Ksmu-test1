# Отчёт о проверке KSMU NOVA · раздельные семестры

- Данные `schedule.json` и `groups.js` побайтово сохранены относительно предыдущей полной NOVA; 242 группы.
- UI-тест Chromium на экранах 320, 390, 768, 1280 px: переключение осень/весна, отображение карточек, центрирование кнопок, без горизонтального переполнения и ошибок JavaScript в проверенных сценариях.
- Реальный тестовый XLSX, лист «Осенний семестр» + выбор «Весенний» → блокирован.
- Реальный тестовый XLSX, лист «Весенний семестр» → черновик после подтверждения; исходные 37 занятий группы 1307 не затронуты.
- После смены семестра ранее загруженный файл сбрасывается и не может быть применён случайно.
- Неполная осенняя выгрузка (2 строки вместо 37) → отдельное подтверждение удаления 37 прежних строк.
- Экспорт черновика содержит academic_year, semester, source, signed_at, comment и список изменённых групп.
- Серверная SQL-схема v2 проверена в SQLite: активная осенняя и весенняя версии одной группы сосуществуют без конфликта уникальности.
- Серверные JavaScript-модули прошли `node --check`; тесты пароля/ролей Supabase (моки) пройдены.
- Продуктовые ограничения: нет боевого интеграционного теста с реальной БД, Telegram, университетскими оригиналами Excel и сервером. Публикация требует отдельной настройки и ручного утверждения.
