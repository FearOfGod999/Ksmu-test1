# KSMU NOVA · Drawer Redesign · 242 группы

Это ПОЛНЫЙ интерфейс NOVA на основе V8.7.1 с исправленной навигацией и расширенным расписанием. Не путать с 108-КБ упрощённым предпросмотрщиком.

## Запуск
- GitHub Pages: загрузить всё содержимое ZIP в корень нового публичного репозитория; Settings → Pages → Deploy from a branch → main / (root).
- Локально: распаковать ZIP целиком; открыть index.html в браузере. Для наиболее надёжной проверки запустить `python -m http.server 8000` и перейти на `http://localhost:8000/`. НЕ открывать `index.html` внутри ZIP.
- Основной сценарий: выбрать группу → Меню (слева сверху) → Сегодня / Расписание / Календарь / Модули / Полезное / Настройки / Поиск.

## Безопасность
`window.KSMU_PREVIEW_ONLY=true` в index.html. Облачные запросы, Telegram-авторизация, серверные черновики/публикация заблокированы для защиты рабочей базы Supabase. Локальные домашние задания и модули сохраняются в localStorage браузера, не распространяются на другие устройства. Полноценная серверная синхронизация здесь намеренно отключена; для неё нужна отдельная тестовая база.

## Данные
- 242 группы; 10 направлений; 6964 пары и 1922 периода циклов из исходных Excel, согласно прошлой сверке. Сохраняется предупреждение о спорных записях 5303и, 8302и, 3401–3404.
- schedule.json — исходные импортированные записи. groups.js — полное JS-представление тех же данных для работы интерфейса.
- Важно: циклы — периоды, не подтверждённые ежедневные пары.
